# Daily arXiv Picks

Since February 2014, [Mauricio Bustamante](https://mbustamante.net/) has kept a daily list of the arXiv preprints he finds interesting. Since October 2017, the list has been public as [My daily arXiv picks](https://mbustamante.net/my-daily-arxiv-picks/).

This repository hosts a single-page, searchable version of all 18,169 picks (February 2014 – November 2026), along with charts of how the picks have changed over time:

**https://mbustama.github.io/daily-arxiv-picks/**

One star (★) marks a paper he found especially interesting; two stars (★★), one that is very relevant to his own work. Topics are assigned by keyword matches on paper titles, so they are approximate, and years come from arXiv identifiers.

The page is a self-contained `index.html`: the data are embedded in it, and search runs in the browser.
